# CTRL+LAB 2027 フロントエンド実装課題

架空のゲームプロトタイプ体験展「CTRL+LAB 2027」のイベントサイトを想定し、完成見本を参考にヘッダーとファーストビュー（ヒーロー部分）を実装してください。

## この課題について

- 制限時間は約60分です。
- HTML / SCSSを中心に実装してください。
- PCとSPの両方に対応してください。
- PCは1440px幅、SPは375px幅を基準にしてください。
- 画面幅768px以下でSPデザインへ切り替えてください。
- 完成見本は`reference/`、分割素材は`public/assets/`にあります。
- 高度なJavaScriptやフレームワーク機能は必要ありません。
- ハンバーガーメニューやリンクの動作実装は不要です。
- 完成させること自体が目的ではありません。考え方や進め方も確認します。
- 見本と完全に同じ1px単位の再現は求めません。
- 不明点や判断に迷う点は、面接官へ自由に質問してください。
- 途中経過や優先順位を面接官と相談しながら進めて構いません。
- インターネット検索と、普段使用しているエディタを利用できます。
- AIを利用したい場合は、事前に面接官へ確認してください。

60分ですべてを実装できない場合は、優先した箇所、未完了の箇所、続ける場合の方針を説明してください。

## セットアップ

Node.js 22を使用します。

```sh
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開いて、実装を始めてください。

ビルド確認は次のコマンドで行えます。

```sh
npm run build
```

## 主な実装場所

- HTML：`src/pages/index.astro`
- 共通スタイル：`src/styles/global.scss`
- ヒーロー：`src/styles/hero.scss`

必要であればファイルを追加・分割して構いません。Sassの変数、ネスト、mixinなどを使うかどうかは自由です。

## 完成見本

- PC（1440 × 900）：`reference/reference_pc.png`
- SP（375 × 812）：`reference/reference_sp.png`

PC版をそのまま縮小するのではなく、SP版では要素の順番、画像の大きさ、情報ブロックの組み方が変わっています。画面幅に応じた見せ方を考えて実装してください。

## 分割素材

- `logo.svg`：イベントロゴ
- `hero-device.png`：試作ゲームデバイス
- `grid.svg`：背景グリッド
- `label-prototype.svg`：試作品ラベル
- `crosshair.svg`：照準風の装飾
- `arrow.svg`：CTA用矢印

素材は必要なものを選んで使用してください。完成見本を1枚の背景画像として配置することは禁止します。

画像の表示サイズやトリミングは、画面幅に合わせて調整して構いません。判断に迷う場合は、実装前または実装途中に面接官へ相談してください。

## 確認したいポイント

この課題では、実装量だけでなく次のような進め方も確認します。

- 見本から必要な要素と優先順位を整理できるか
- 不明点や前提を言葉にして確認できるか
- 作業状況や問題点を簡潔に共有できるか
- 制限時間に応じて実装範囲を調整できるか
- PC/SPの違いを説明しながら実装できるか

完璧な再現よりも、面接官と認識を合わせながら進めることを重視してください。
